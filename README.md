# OpenWorker Task Oriented AI Demo

This example demonstrates the core concept of Andrew Ng's OpenWorker: an AI that goes beyond simple conversation to autonomously identify and execute specific tasks. It contrasts a traditional chatbot, which primarily provides textual responses, with a simulated task-oriented AI that 'performs' actions based on user prompts, illustrating the difference between chatting and task completion.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
